Thesis Project

Facial Recognition Enabled Access Monitoring System

A machine learning-based access control system integrating facial detection technology for automated gate operation.

Overview

An access monitoring system that combines facial recognition, a PHP web dashboard, and Arduino UNO gate automation.

Problem

The system needed automated access control, attendance tracking, and logging in a controlled local environment with physical hardware.

Solution

Integrated facial detection with Arduino UNO so a successful recognition event could trigger the gate mechanism and record the event in the dashboard.

Features

Automated attendance, real-time logging, access monitoring, database management, and a PHP-based web dashboard.

Technology

PHP 8, Python 3, OpenCV, Arduino UNO, HTML5, JavaScript, Tailwind CSS, and MySQL.

My Contribution

Built the web dashboard, database workflow, and integration around the hardware and recognition flow.

Challenges

The project required a physical Arduino UNO device and a local camera environment, so it could not be hosted like a normal online demo.

Result / Learning

The project strengthened my understanding of machine learning, web development, database work, and hardware integration. It also supported real-time monitoring of 500+ student records, improved report generation time by 50%, and helped reduce false positives by 20%.
