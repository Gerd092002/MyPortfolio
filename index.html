Academic thesis

Facial Recognition Enabled Access Monitoring System

An academic prototype combining local facial recognition, access records, and a physical gate-control setup.

Problem

Access monitoring needed to connect camera-based recognition with stored records and an automated physical response.

Solution

Combined a Python/OpenCV recognition process, a PHP monitoring dashboard, MySQL records, and Arduino UNO hardware in a local setup.

My role

The existing thesis description identifies my contribution in the web dashboard, database workflow, and integration around recognition and hardware.

Features

Project materials describe facial recognition-based access monitoring, event/attendance logging, and Arduino-triggered gate operation.

Architecture

The diagram is a redrawn version of the conceptual Input–Process–Output framework you provided. It represents facial, enrollment, and administrative inputs; the system's five processing modules; physical and digital outputs; administrator and authorized-user roles; and the feedback loop. It is not a wiring diagram or a capture from a running deployment.

Stack

PHP 8, Python 3, OpenCV, Arduino UNO, HTML5, JavaScript, Tailwind CSS, and MySQL.

Challenge

The system depends on physical Arduino hardware and local camera access. Those dependencies make it unsuitable for a conventional public web demo.

Outcome & verification

The résumé reports 500+ student records, 50% faster report generation, 95% recognition accuracy, and 20% fewer false positives. These are résumé-reported figures, not independently reproduced or verified for this review.
